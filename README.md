# UCT Intelligent Connectivity Group

Research in intelligent networks, connected sensing and secure systems at the University of Cape Town's Department of Electrical Engineering.

[Website](https://uct-intelligent-connectivity-group.github.io/)

## Local development

Requires Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

- Website: http://127.0.0.1:4321/
- Local CMS: http://127.0.0.1:8082/

```sh
npm run check
npm run build
```
